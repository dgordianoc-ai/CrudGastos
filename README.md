# CRUD de Gastos

## Descripción
Aplicación de consola desarrollada en C# para registrar, listar, buscar, actualizar y eliminar gastos utilizando SQL Server LocalDB.

## Requisitos
- Visual Studio
- .NET
- SQL Server LocalDB
- Base de datos `GastosDB` con la tabla `Gastos`

## Ejecución
1. Abrir el proyecto `CrudGastos` en Visual Studio.
2. Verificar la cadena de conexión en `GastoRepositorio.cs`.
3. Compilar el proyecto.
4. Ejecutar la aplicación y seleccionar una opción del menú.

## Funcionalidades
- Registrar gastos.
- Listar gastos y calcular el total.
- Buscar gastos por ID.
- Actualizar el monto de un gasto.
- Eliminar gastos.
- Manejar errores de SQL Server.

## Pruebas realizadas
Se verificaron las operaciones del CRUD, la búsqueda de registros inexistentes y el manejo de errores de conexión.
